Instrucciones para GitHub Pages

  1. Los cursos se guardan en el archivo courses.js (separado del código).
  2. Opción A (recomendada): edita courses.js directamente y sube index.html + courses.js a la raíz de tu repositorio de GitHub Pages.
  3. Opción B (desde el panel): edita los cursos aquí, pulsa Descargar courses.js para guardar el catálogo, o Descargar HTML para un archivo único autocontenido.
  4. Renombra el archivo descargado a index.html si usas la Opción B.
  5. Súbelo a la raíz de tu repositorio de GitHub Pages (reemplaza el anterior).
  6. Espera 1-2 minutos y recarga tu sitio.
